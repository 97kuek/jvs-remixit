# 研究の目的と動機 — なぜ RemixIT × TF-Locoformer なのか

> 発表で「最終目的・動機・手法選定の理由」を問われたときの回答の背骨。
> 関連: [03_decision_log.md](03_decision_log.md) / [04_experiment_plan.md](04_experiment_plan.md)

## 1. 最終目的(なにを実現したいか)

**正解データが存在しない実世界の音声に対して、話者が重なった区間を高品質に分離できる技術を実現する。**

具体的な応用イメージ:
- 音声対話モデル(J-Moshi 系など)の学習データ作成: 実会話コーパス(J-CHAT 等、日本語で約69,000時間規模)の重なり発話は、ダイアライゼーションベースの処理では破綻する。真の話者分離が必要
- 会議録・字幕・ASR の前処理: 実録音の重畳区間の書き起こし精度改善
- 日本語には大規模な実会話音声はあるが、「混合音と正解クリーン音声のペア」は実録音では原理的に作れない

## 2. 課題の構造(なぜ簡単ではないか)

音源分離モデルの学習は通常、クリーン音声を人工的に混ぜた**シミュレーション混合**での教師あり学習に依存する。しかし:

1. **実データに正解がない**: 実会話の混合音から正解クリーン音声は得られない → 教師あり学習が適用できない
2. **ドメインミスマッチ**: シミュ混合で学習したモデルは、言語・録音条件・話し方が違う実データで性能が劣化する
3. つまり本質課題は「**ラベルなしの対象ドメイン混合音だけで、分離モデルを適応させる**」こと

## 3. なぜ RemixIT か(手法選定の理由)

対象ドメインで入手できるデータの制約が最も緩い自己学習フレームワークだから。

| 学習法 | 対象ドメインで必要なもの | 実会話への適用 |
|---|---|---|
| 教師あり | クリーン音声+ノイズ(ペア合成) | 不可能(正解がない) |
| MixIT | 孤立したソース録音(ノイズ単体等) | 困難(孤立音源も普通ない) |
| **RemixIT** | **混合音だけ** | **可能** |

さらに RemixIT は:
- 教師の推定を再混合(リミキシング)して疑似ペアを無限に生成でき、**教師が不完全でも生徒が教師を超えて改善していく**理論保証と実証がある(教師更新プロトコル)
- アーキテクチャ非依存 → 好きな分離モデルを生徒にできる

## 4. なぜ TF-Locoformer か(モデル選定の理由)

1. **分離品質の天井はアーキテクチャで決まる**。RemixIT は疑似ターゲットの質=教師・生徒の推定品質に依存するため、強いアーキテクチャと組むほど枠組み全体が活きる
2. TF-Locoformer は TF 領域デュアルパスの **SoTA 級**(WSJ0-2mix 24.2dB、WHAMR! で TF-GridNet 超え)で、**残響・雑音のある実環境条件に強い TF 領域**モデル
3. RNN フリー(Transformer + 畳み込み)で学習が並列化でき、限られた計算資源・期間でも回しやすい。公式実装が公開されており実装リスクが低い
4. **研究としての空白**: RemixIT 原論文(2022)の検証は軽量時間領域モデル(Sudo rm -rf, 0.56M)のみ。「SoTA の TF 領域 Transformer を教師・生徒にしたとき自己学習がどう振る舞うか」は未検証

→ 「制約の最も緩い自己学習(RemixIT)」×「最強クラスの分離アーキテクチャ(TF-Locoformer)」の組み合わせは、最終目的(正解なし実データの分離)への最短経路として必然性がある。

## 5. proken-A のスコープ(最終目的への位置づけ)

最終目的(実会話分離)をいきなりやると正解がなく定量評価できないため、本プロジェクトでは**定量評価可能な形でこの枠組みの有効性を検証する**:

**「英語データで学習された分離モデル(教師)を、正解ラベルなしの日本語混合音(JVS シミュ)だけで TF-Locoformer(生徒)に適応させ、クロスリンガルなドメインギャップを自己学習で埋められるかを SI-SNRi で定量検証する」**

- 言語ミスマッチ(英語→日本語)を「制御されたドメインギャップ」として使う。実会話適応の縮小版・検証可能版
- 正解は評価のみに使用し、学習には一切使わない(RemixIT の設定に忠実)
- 将来展望: 本検証で有効性が示されれば、同じ枠組みを J-CHAT 等の実会話(正解なし)へ展開する

## 6. 想定 Q&A(発表用)

- **Q: 英語の教師が日本語を分離できるのか?**
  A: 話者分離の主な手がかり(ピッチ・声色・調波構造などの話者性)は言語非依存性が高く、ゼロショットでもある程度動く見込み。ただし劣化はするはずで、**その劣化分を正解なしでどこまで回復できるかがまさに本研究の主題**。教師の初期品質は実験 E0 で必ず測定し、破綻していた場合のフォールバックも用意している(→ 03_decision_log.md DEC-007)
- **Q: 最初から日本語で教師を学習すればよいのでは?**
  A: JVS のようなクリーン読み上げ音声ならそれが可能だが、最終目的の実会話ドメインでは正解が作れないためその戦略は使えない。「正解が作れないドメインに適応する」枠組みの検証こそが目的であり、教師を対象ドメインで教師あり学習してしまうと研究課題自体が消える
- **Q: JVS に「正解」はあるのか? 正解なし学習と矛盾しないか?**
  A: JVS は話者ごとに別録りされたクリーン読み上げ音声のコーパス。2話者混合音は自分で足し合わせて作る(シミュレーション混合)ため、混ぜる前のクリーン音声=正解が手元に残る。本研究ではこの正解を**学習には使わず封印し、評価にだけ使う**。これにより「正解が存在しない実会話と同じ学習条件」を保ちながら、改善を SI-SNRi で数値化できる
- **Q: なぜ JVS でやるのか(実データでやらないのか)?**
  A: 実データ(J-CHAT)には正解がなく改善を数値で示せない。まず正解のあるシミュ環境でドメイン適応の効果を定量的に立証するのが科学的な手順。実データ適用は将来展望(または試聴デモ)
