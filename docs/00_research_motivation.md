# 研究の目的と動機

> 関連: [03_decision_log.md](03_decision_log.md) / [04_experiment_plan.md](04_experiment_plan.md)

## 1. 最終目的

- 正解データが存在しない実世界の音声から、話者が重なった区間を高品質に分離できる技術を作りたい
- 具体的な応用
  - 音声対話モデル(J-Moshiなど)の学習データ作り
  - J-CHATなどの実会話コーパスの重なり発話は、話者の区間だけを推定する従来の処理では対応できない
  - 日本語には大規模な実会話音声はあるが、「混合音とその正解のクリーン音声」のペアは実録音からは原理的に作れない

## 2. 課題の構造

- 音源分離モデルの学習は通常、クリーン音声を人工的に混ぜた模擬混合音での教師あり学習に頼る
- しかし次の2つの問題がある
  1. 実データには正解がない
  2. 学習時と条件が違う
- つまり本質的な課題は、「正解ラベルのない対象データの混合音だけで、分離モデルを適応させる」こと

## 3. なぜ RemixIT か

- 対象データについて必要とする条件が最も緩い自己学習の枠組みだから

| 学習方法 | 対象データに必要なもの | 実会話への適用 |
|---|---|---|
| 教師あり学習 | クリーン音声とノイズのペア | 不可能(正解がない) |
| MixIT | 分離済みのノイズ録音 | 難しい(分離済みの録音も普通ない) |
| RemixIT | 混合音だけ | 可能 |

- さらにRemixITには次の利点がある
  - 教師の推定結果をリミキシングすることで疑似的な正解ペアを無限に作れる
  - 教師の推定が不完全でも、生徒が教師を超えて改善していくことが理論と実験の両方で示されている
  - 使うモデルの種類を選ばない
  - 好きな分離モデルを生徒にできる

## 4. なぜ TF-Locoformer か

1. 分離できる品質の上限はモデルの性能で決まる。RemixITは疑似的な正解の質(教師と生徒の推定の質)に依存する手法なので、性能の高いモデルと組むほど枠組み全体が活きる
2. TF-Locoformerは時間・周波数の両方を扱う方式の中で最高水準の性能を持つ(WSJ0-2mixで24.2dB、雑音・残響つきのWHAMR!でTF-GridNetを上回る)。実環境に近い雑音・残響のある条件に強い
3. RNNを使わない(Transformerと畳み込みのみの)構成のため学習を並列化でき、限られた計算資源と期間でも回しやすい。公式実装が公開されており、実装のリスクが低い
4. 研究としての空白がある: RemixITの元論文(2022年)は軽量な時間領域モデルだけで検証している。最新の高性能なモデルを教師・生徒にしたとき自己学習がどう振る舞うかは、まだ確かめられていない

- まとめると、「対象データへの制約が最も緩い自己学習の手法(RemixIT)」と「性能が高い分離モデル(TF-Locoformer)」の組み合わせは、最終目的(正解のない実データの分離)に向けた自然な選択だと言える

## 5. このプロジェクトの範囲

- 最終目的(実会話の分離)をいきなり扱うと正解がなく、成果を数値で示せない。そこで本プロジェクトでは、数値で示せる形でこの枠組みの有効性を確かめる
- 研究課題: 「英語のクリーンな音声で学習された分離モデル(教師)を、正解ラベルなしの『雑音つき日本語混合音』(JVSとWHAM! noiseで作った模擬データ)だけを使ってTF-Locoformer(生徒)に適応させ、言語と録音環境という2種類の違いを自己学習でどこまで埋められるかを、SI-SNRという指標で確かめる」
- 言語の違い(英語→日本語)と録音環境の違い(クリーン→雑音あり)を、条件をそろえた形での「大きな違い」として利用する。実会話への適応を、確かめられる形に縮小したものと位置づける
- 正解は評価にだけ使い、学習には一切使わない(RemixITの前提を守る)
- 今後の展望: この検証で有効性が確かめられれば、同じ枠組みをJ-CHATなどの実会話(正解なし)に広げる

### 設計を見直した経緯(2026-07-20)

- 当初はクリーンなJVSの混合音だけを想定していた
- しかし予備実験(E0)で、英語の教師が追加学習なしでもクリーンな日本語の混合音をSI-SNR改善量25dBほど分離してしまい、埋めるべき違いがほとんど残らないと分かった
- これは「クリーンな読み上げ音声の話者分離では、言語の違いだけではほとんど障害にならない」という副次的な発見であり、これ自体発表で語れる
- そこで適応先に環境の雑音(WHAM! noise)を加え、教師が明らかに性能を落とす条件(SI-SNR改善量が数dBまで下がる)を作ってからRemixITの検証に進んだ(詳しくは[03_decision_log.md](03_decision_log.md)のDEC-010と[07_results.md](07_results.md)を参照)

## 6. 想定される質問と答え(発表用)

- 問い: 英語の教師が日本語を分離できるのか
  - 答え: 話者分離の主な手がかり(声の高さ・声色・音の構造といった話者ごとの特徴)は言語によらない部分が大きく、追加学習なしでもある程度は動くと見込んでいた。ただし性能は落ちるはずで、その落ちた分を正解なしでどこまで取り戻せるかが本研究の主題である。教師の最初の性能は実験E0で必ず測り、性能が大きく落ちていた場合の代わりの案も用意している([03_decision_log.md](03_decision_log.md)のDEC-007)
- 問い: 最初から日本語で教師を学習すればよいのではないか
  - 答え: JVSのようなクリーンな読み上げ音声なら可能だが、最終目的である実会話では正解が作れないためこの方法は使えない。「正解が作れない対象への適応」という枠組みそのものを確かめるのが目的であり、教師を対象データで教師あり学習してしまうと、確かめたい課題自体がなくなってしまう
- 問い: JVSに「正解」はあるのか。正解なしの学習と矛盾しないか
  - 答え: JVSは話者ごとに別々に録音されたクリーンな読み上げ音声のコーパスである。2話者の混合音は自分で足し合わせて作る(模擬混合)ため、混ぜる前のクリーンな音声、つまり正解が手元に残る。本研究ではこの正解を学習には一切使わず、評価にだけ使う。これにより「正解が存在しない実会話と同じ学習条件」を保ちながら、改善をSI-SNRという数値で示せる
- 問い: なぜJVSで行うのか。実データで行わないのか
  - 答え: 実データ(J-CHAT)には正解がなく、改善を数値で示せない。まず正解のある模擬環境で適応の効果を数値として示すのが手順として妥当である。実データへの適用は今後の展望、または聞き比べのデモとして扱う
- 問い: なぜ雑音(WHAM! noise)を加えたのか。最初からその設計だったのか
  - 答え: 当初はクリーンなJVSの混合音だけを想定していた。しかし予備実験(E0)で、英語の教師が追加学習なしでもクリーンな日本語の混合音を25dBほど分離してしまい、RemixITで埋めるべき違いがほとんど残らないと分かった。そこで適応先に環境の雑音を加え、教師が明らかに性能を落とす条件(数dBまで下がる条件)を作った。この経緯自体、「クリーンな読み上げ音声の話者分離では言語の違いだけでは障害にならない」という発見を含んでおり、発表で語れる内容になっている
