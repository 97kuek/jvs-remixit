## 研究課題

- 英語のクリーンな環境で学習された分離モデルを教師とし、正解ラベルなしの「雑音つき日本語混合音」だけを使ったRemixITの自己学習で、TF-Locoformerの生徒を、言語の違いと録音環境の違いという2種類の違いに適応させられるか
- 元論文からの違い1(タスク): RemixITを音声強調から2話者分離に拡張する(混ぜ直しは話者の推定をバッチ内で入れ替える、生徒の損失はPIT+SI-SNR)
- 元論文からの違い2(モデル): 軽量な時間領域モデルから、時間・周波数の両方を扱う高性能なTF-Locoformerに変える
- 元論文からの違い3(設定): 言語の違い(英→日)を、条件をそろえた「大きな違い」として使い、数値で検証する
- 関連研究: Self-Remixing(Saijo & Ogawa, ICASSP 2023)は混ぜ直しを使った正解なしの分離だが、混合音を作り直せているかを見る損失を使う。本研究はRemixIT型(音源ごとの疑似的な正解+教師の継続更新)である点が異なる。発表で必ず触れる

## データの構成

| 役割 | データ | 備考 |
|---|---|---|
| 教師 | MERL公開のTF-Locoformer(8kHz、Medium、パラメータ数15M)をそのまま利用(追加学習なし) | E0でWSJ0-2mix / Libri2mix / WHAMR!版を比較し、最も良いものを採用した |
| 適応先(生徒の学習) | jvs2mix_noisy: JVSの2話者混合 + WHAM! noise(SNR一様[-6,+3]dB、WHAM!の設定にならう) | 正解は学習に使わない(mixだけを使う)。話者・雑音とも学習・検証・評価で重ならないように分ける |
| 対照条件 | jvs2mix(クリーン版、生成済み) | E0済み: WSJ0 19.66 / Libri 25.37 dB([07_results.md](07_results.md)) |
| 評価 | jvs2mix_noisyの評価用1000件(正解あり) | PITでのSI-SNR改善量 |
| (余裕があれば) | J-CHATの実会話区間 | 聞き比べのデモのみ。数値での評価はしない |

- 決まっている設計: 8kHzで統一(DEC-008)、混合の条件はSNR一様[-5,5]dB・短い方に合わせる(DEC-008)、学習用20,000件・検証用1,000件・評価用1,000件
- 実測: 2080 Ti(11GB)ではバッチサイズ2×セグメント長4秒+勾配の蓄積2の組み合わせで動く(バッチサイズ4はメモリ不足になる)

## 実験の一覧(優先度順)

| 番号 | 実験 | 目的 | 判定 |
|---|---|---|---|
| E0 | 英語教師をJVSの評価データで追加学習なしのまま評価する | 下限の確認 + 進めてよいかの判定(DEC-007) | SI-SNR改善量が5dB以上なら進める。届かなければ教師を少量の正解で軽く追加学習し、半教師あり設定に切り替える |
| E1 | TF-Locoformer(縮小構成)をJVSの学習データで教師あり学習する | 上限の目安 | — |
| E2 | RemixIT(教師を固定したまま)で生徒を学習する | 提案手法の最小構成 | E0を上回るか |
| E3 | RemixIT(教師を逐次更新する) | 教師を継続的に更新する効果を見る(本命) | E2を上回るか |
| E4 | (余裕があれば)混ぜ直しをしない単純な蒸留、または移動平均での教師更新 | 混ぜ直しがどれだけ効いているかを切り分ける | — |

- 主な結果の見せ方: 「E0(英語教師そのまま)→ E2/E3(正解なしで適応した後)→ E1(教師あり学習の上限)」というSI-SNR改善量の並びで、「正解なしで違いをどこまで埋められたか」を示す

## 手法の設計(RemixITの2話者分離への拡張)

```
教師 f_T: MERL公開のTF-Locoformer(英語)     生徒 f_S: TF-Locoformer Small以下(2出力)

各ステップ:
1. 日本語の混合音バッチ m_b (b=1..B, B≥2) を取り出す
2. 教師が推定する: (s̃1_b, s̃2_b) = f_T(m_b)
3. 混ぜ直す: m̃_b = s̃1_b + [P s̃2]_b   (P: バッチ内での入れ替え)
4. 生徒を学習する: L = PIT-SI-SNR( f_S(m̃_b), (s̃1_b, [P s̃2]_b) )
5. 一定ステップごとに教師を更新する(E3: 生徒の重みをそのまま教師にコピーする)
```

- jchat-sepからの教訓(参照: `../../jchat-sep/docs/decisions/`)
  - 学習率は最初から自動で決める(最初上げてから徐々に下げる方式)。途中で手動で変えるとやり直しがきかなくなる
  - RemixITのバッチサイズは2以上が必須(バッチ内での入れ替えのため)
  - RemixITの検証損失は「教師との一致度」であり、分離そのものの品質ではない。おかしくなっていないかを見るためだけに使い、品質の判断は正解ありの模擬評価で行う

## 計算資源の割り当て(2080 Ti 11GB×3)

- GPU0: E1(教師あり学習の上限) / GPU1: E2 → E3 / GPU2: 予備・E4
- 生徒はTF-Locoformer Small(パラメータ数5M)以下、セグメント長4秒、バッチサイズ2〜4+勾配の蓄積
