## 研究課題 (RQ)

**RQ: 英語クリーン環境で学習された分離モデルを教師とし、正解ラベルなしの「雑音つき日本語混合音」のみを用いた RemixIT 自己学習で、TF-Locoformer 生徒を言語・音響環境の両ドメインギャップに適応させられるか?**

- 差分1(タスク): RemixIT を音声強調 → 2話者分離に拡張(リミキシング=話者スロットのバッチ内置換、生徒損失=PIT + SI-SNR)
- 差分2(モデル): 軽量時間領域モデル → TF 領域 SoTA の TF-Locoformer
- 差分3(設定): 言語ミスマッチ(英→日)を制御されたドメインギャップとして定量検証
- 関連研究: Self-Remixing (Saijo & Ogawa, ICASSP 2023) はリミキシングベースの教師なし分離だが混合音再構成損失。本研究は RemixIT 型(音源レベル疑似ターゲット+教師継続更新)である点が異なる。発表で必ず言及

## 実験マトリクス(優先度順)

| # | 実験 | 目的 | 判定 |
|---|---|---|---|
| E0 | 英語教師を JVS test でゼロショット評価 | ベースライン(下限)+ **Go/No-Go ゲート**(DEC-007) | SI-SNRi ≥ 5dB で Go。未満なら教師を少量ラベルで fine-tune し半教師あり設定に切替 |
| E1 | TF-Locoformer(縮小構成)を JVS train で教師あり学習 | 上限(オラクル) | — |
| E2 | RemixIT(static 教師)で生徒学習 | 提案の最小構成 | E0 を上回るか |
| E3 | RemixIT(sequential 教師更新) | 教師継続更新の効果(本命) | E2 を上回るか |
| E4 | (余裕があれば)リミキシングなし単純蒸留 / EMA 教師 | リミキシングの寄与切り分け | — |

主結果の見せ方: **E0(英語教師そのまま) → E2/E3(ラベルなし適応後) → E1(教師あり上限)** の SI-SNRi 序列で、「正解なしでギャップをどこまで埋めたか」を示す。

## 手法設計(RemixIT の 2話者分離拡張)

```
教師 f_T: MERL 公開 TF-Locoformer(英語)     生徒 f_S: TF-Locoformer Small 以下(2出力)

各ステップ:
1. 日本語混合音バッチ m_b (b=1..B, B≥2) をサンプル
2. 教師推定: (s̃1_b, s̃2_b) = f_T(m_b)
3. リミキシング: m̃_b = s̃1_b + [P s̃2]_b   (P: バッチ内置換)
4. 生徒学習: L = PIT-SI-SNR( f_S(m̃_b), (s̃1_b, [P s̃2]_b) )
5. K ステップごとに教師更新(E3: θ_T ← θ_S)
```

jchat-sep からの教訓(参照: ../../jchat-sep/docs/decisions/):
- 学習率は warmup + cosine で最初から自動スケジュール化(途中の手動変更は再現性を壊す)
- RemixIT の batch size は 2 以上必須(バッチ内置換のため)
- RemixIT の検証損失は「教師との一致度」であり分離品質ではない。発散検知用と割り切り、品質判断は正解ありシミュ評価で行う
