# 発表資料の骨子 (下書き, 2026-07-29時点)

- 発表日 2026-08-10 に向けた構成案。確定した数値と、まだ結果待ちの部分を分けて書く
- スライド化する際はこの順番のまま使える想定。詳細な数値・根拠は各スライド案の下にリンクした資料を見ること

## 1. タイトル・一言でいうと

- 「英語の分離モデルを、正解ラベルなしの雑音つき日本語混合音だけでRemixIT自己学習によって適応させられるか」
- 副題候補: 「言語と録音環境、二重のギャップへの挑戦」

## 2. 動機(確定)

- 最終目的: 実会話(J-CHATなど)の重なり発話を、正解のない状態で分離したい
- 課題: 正解ラベルのない対象データだけで分離モデルを適応させる必要がある
- 手法: RemixIT(対象データへの制約が最も緩い自己学習)× TF-Locoformer(時間・周波数の両方を扱う高性能モデル)
- 詳細: [00_research_motivation.md](00_research_motivation.md)

## 3. 研究設計(確定)

- 教師: 英語で学習済みの公開TF-Locoformer(MERL、WHAMR!版)
- 適応先: JVS(日本語)の2話者模擬混合 + WHAM! noise(雑音)
- 言語の違い(英→日)と録音環境の違い(クリーン→雑音)を、条件をそろえた「大きな違い」として利用
- 評価: 正解ラベルは評価にだけ使う。SI-SNRの改善量で数値化
- 詳細: [04_experiment_plan.md](04_experiment_plan.md)

## 4. 実験の全体像(確定)

- E0: 教師をそのまま評価(下限・進めてよいかの判定)
- E1: 教師あり学習の上限(オラクル)
- E2: RemixIT(教師固定)
- E3: RemixIT(教師を逐次更新)
- 主結果の見せ方: 「E0 → E2/E3(正解なしの適応) → E1(上限)」の並びで、正解なしでどこまで埋められたかを示す

## 5. 結果1: E0(確定)— 言語の違いは単体では障害にならない

- クリーンな日本語混合では、英語教師が追加学習なしでSI-SNR改善量25dBほど分離できてしまった(目安の5dBを大きく超えて余裕でGo)
- これは「クリーンな読み上げ音声どうしの話者分離では、言語の違いだけではほとんど障害にならない」という副次的な発見であり、それ自体語れる知見
- そこで適応先を雑音つきに難しくした(WHAM! noise追加)
- 雑音つきでは英語教師は大きく劣化する: WSJ0-2mix 0.57dB / Libri2mix 3.18dB / **WHAMR! 9.09dB**(採用教師)
- 図案: クリーン vs 雑音つきでの3教師のSI-SNR改善量を棒グラフで対比
- 詳細: [07_results.md](07_results.md) E0の節

## 6. 結果2: E1(確定)— 教師あり学習の上限

- 同じ雑音つきデータで、正解ラベルを使って教師あり学習した場合の上限: **SI-SNR改善量13.23dB**
- 教師そのまま(9.09dB)との差、約4.1dBが「正解なしでRemixITがどこまで埋められるか」の目標
- 詳細: [07_results.md](07_results.md) E1の節

## 7. 結果3: E2/E3(RemixIT)— ここが本題、二通りの見せ方を用意

### 7-A. うまくいった場合(バッチサイズ拡張の効果が確認できた場合)

- 見せ方: E0(9.09dB)→ E2/E3(改善後の値)→ E1(13.23dB)の並びで、正解なしでギャップの一部を埋められたことを示す
- 併せて、途中でぶつかった壁とその解決の過程も「工学的な貢献」として語る(次項)
- **この節は結果が出てから具体的な数値で埋める**

### 7-B. 明確な改善が見られなかった場合(限界を示す結果として組む)

- 主張: 「教師の性能が中程度(9.09dB)で、言語+雑音という二重のドメインギャップがある条件では、素朴なRemixIT拡張は正解なしで改善を出すのが難しい」
- この結果自体が価値を持つ理由:
  - RemixIT原論文は軽量な時間領域モデル・単一のドメインギャップ(音声強調)でしか検証していない。より難しい条件(2話者分離+二重ギャップ)での限界を明らかにしたこと自体が新しい知見
  - 単に「動かなかった」ではなく、**原因を段階的に切り分けた過程**が研究として語れる(次項8)
- 数値: E0(9.09dB)→ E2最終(−1.61dB)→ E1(13.23dB)。正解なしの自己学習がむしろ教師より悪化した、という対比を明確に見せる

## 8. 関連研究との位置づけ(確定、結果によらず語れる内容)

- **CHiME-7 UDASE(2023年の国際チャレンジ)の公式ベースラインはRemixITそのもの**。実会話への教師なし適応で、人間による聞き比べ評価では、提出手法4つのうち3つが無加工の入力音声より総合品質が低いと判定された(論文でも「この課題の難しさを浮き彫りにした」と明記)
- 教師なし2話者分離の学習不安定性は、Waseda大学の一連の研究(Self-Remixing, Enhanced Reverberation as Supervision等)が専用の損失項を必要としたほど、独立に繰り返し報告されている既知の難所
- **結論**: 本研究がE2/E3でぶつかった「学習が進むほど実分離品質が悪化する」問題は、実装のミスというより、この分野の第一線でも解決されていない本質的な難しさに当たったと位置づけられる。これにより結果の解釈に説得力を持たせられる
- 詳細: [09_related_work_review.md](09_related_work_review.md)

## 9. 診断の過程(確定、結果によらず語れる内容)— ここが独自性のアピールになる

- 発見1: 生徒の出力音量が入力の90〜130倍という異常
- 検証1: mixture consistency補正を試したが、むしろ悪化した(環境雑音を話者推定に混入させるため)。「音量の異常はSI-SNRのスケール不変性のため直接の原因ではない」と正しく切り分けられた
- 発見2: リミキシングで話者2のスロットを別録音に入れ替えると、環境雑音が二重に重なる非現実的な疑似混合になっていた(DEC-016)
- 対応: 雑音を第3の出力として明示的に分離する構成に変更 → 学習序盤は改善したが、学習が進むと再び悪化する傾向が見えた
- セカンドオピニオン(独立したAIエージェントによるレビュー)を活用し、バッチサイズがRemixITの理論的前提に対して小さすぎる可能性など、追加の要因を洗い出した
- 図案: 「入力音量異常の発見 → consistency補正の失敗による原因の絞り込み → 雑音分離の構成変更 → バッチサイズの検証」という一連の流れをタイムラインで見せる

## 10. 考察・今後の展望(確定部分+結果待ち部分)

- 確定: 言語の違い単体は、クリーンな条件では話者分離の障害にならない(E0の発見)
- 確定: 教師の性能が中程度の場合、正解なしの自己学習で上限との差を埋めるのは容易ではない(RemixITの理論的前提や役割の固定など、複数の要因が絡む。分野全体でも未解決、8節参照)
- 結果待ち: バッチサイズ拡張後の傾向次第で、「効果があった」と「今回の条件・期間では効果を確認できなかった」のどちらかを書く
- 今後の展望: 教師の質そのものを上げる、雑音残差の質を改善する、教師更新の頻度を変える、といった方向性(実施はしていないが今後の課題として言及)
