# 論文ノート: RemixIT (Tzinis et al., 2022)

> RemixIT: Continual self-training of speech enhancement models via bootstrapped remixing
> arXiv:2202.08862v3 / IEEE JSTSP

## 一言でいうと

- クリーン音声もノイズ単体の波形も一切使わず、対象領域のノイズ入り混合音だけで音声強調モデルを自己学習させる手法
- 教師モデルと生徒モデルの2つを使う枠組みと、「推定結果を混ぜ直す(リミキシング)」処理が肝

## 問題設定

- 音声強調とは、混合音 m = s + n から音声 s を復元するタスク
- 教師あり学習はクリーン音声 D_s とノイズ D_n のペアが必要。実環境では学習時と条件が違う(領域の不一致)ことに弱い
- MixIT は、対象領域で分離済みのノイズ録音が必要という制約がある
- RemixIT は対象領域の「混合音データセット D_m」だけでよい。3つの中で最も制約が緩い

## 手法の流れ (Algorithm 1)

1. 教師の事前学習: 対象領域の外にあるデータで教師モデル f_T を学習する(教師あり学習でもMixITでもよい)
2. 対象領域の混合音バッチ m ~ D_m に対して、教師が音声とノイズを推定する: (s̃, ñ) = f_T(m)
3. 混ぜ直し(リミキシング): バッチ内でノイズの推定 ñ をランダムに入れ替え、音声の推定と足し合わせる: m̃ = s̃ + P ñ
4. 生徒 f_S は m̃ を入力とし、教師の推定 (s̃, Pñ) を正解の代わり(疑似ターゲット)として通常の教師あり学習と同じ損失で学習する
5. 教師の継続更新: 一定ステップごとに教師を生徒の重みで更新する
   - 逐次更新: θ_T ← θ_S(20エポックごとに置き換え)。基本の方式
   - 移動平均更新: θ_T ← γθ_S + (1−γ)θ_T、γ=0.01。データ量が少ない適応で使う

## なぜ効くか(理論)

- RemixITの損失は、教師あり学習の損失 + 教師の誤差の大きさ(生徒からは変えられない定数) − 生徒の誤差と教師の誤差の相関、の3つに分解できる
- 混ぜ直しによって同じ教師の音声推定が多様なノイズと混ざるため、生徒の誤差と教師の誤差の相関が平均するとゼロに近づく。バッチ数を増やすほど、RemixITの損失の勾配は正解を使った教師あり学習の勾配に近づくことが証明されている(Theorem II.1)
- 教師の推定がかなり悪くても(SI-SNRが5dB未満でも)生徒は改善できることが実験で示されている(Fig. 5)

## 実験の設定(参考にすべき点)

- モデル: Sudo rm -rf(軽量な時間領域モデル、パラメータ数0.56M〜0.79M)。手法は使うモデルの種類を選ばないと明言している
- 出力は2つ(音声とノイズ)。「音声+ノイズ=入力の混合音」になるよう強制する層を入れている
- 損失: 負のSI-SDR、最適化手法はAdam、学習率1e-3(6エポックごとに半分に)、バッチサイズ2、16kHz
- データセット: DNS2020 / LibriFSD50K (LFSD) / WHAM! / VCTK-DEMAND
- 評価指標: SI-SDR(改善量)、PESQ、STOI

## 主要な結果

- DNSのテストデータ: 教師(対象領域外データでMixIT学習、14.8dB)→ 生徒 16.0dB(SI-SDR)。比較したMixIT系の手法をすべて上回る
- 半分だけ正解を使う設定(LFSDで教師あり事前学習→DNSに適応): 17.6 → 18.0dB
- 追加学習なしでの適応(移動平均での教師更新): 0.8dB程度の改善
- 対象領域のノイズ録音が一部使えるなら、実ノイズと教師推定ノイズを混ぜる拡張(式17)でさらに改善する

## この研究プロジェクトへの示唆

- RemixITは使うモデルの種類を選ばないため、Sudo rm -rfをTF-Locoformerに置き換える案は手法の趣旨に合っている
- 元の論文は軽量な時間領域モデルだけで実験している。時間と周波数の両方を扱う強いモデルで検証する価値がある(新しさの芽)
- 教師の事前学習にはコストがかかる。学習済みのチェックポイントを使う、または小さいコーパスで規模を縮小するのが現実的
- 教師の更新方法(逐次更新か移動平均か)は、適応に使えるデータの量で選ぶとよい
